FAQ

Fragen zum Kauf

Beauftragung außerhalb Koreas.

Zahlt man im Studio?

Noch nicht. Das Studio dient der Auswahl. Kauf und Rechnung laufen über E-Mail-Angebot. Private und Institutionen schreiben an studio@publicbloom.art.

Was wird geliefert?

Meist eine 4K-mp4 auf Ihr Panel. Soll der Screen mit Wetter oder Daten wechseln, erhalten Sie Live-Code auf einem Player, den das Studio einrichten kann. Fehlt ein Screen, kommt LED- oder Projektorinstallation ins selbe Gespräch.

Die Oberfläche ist koreanisch. Kann ich sie trotzdem nutzen?

Ja. Sie wählen Bilder, Paletten, Bewegung — Sie schreiben keinen koreanischen Text. Wer den Editor meidet, schickt ein Referenzbild und bittet um drei Entwürfe. Diese deutsche Seite macht das Angebot klar, bevor Sie das Werkzeug öffnen.

Aufträge aus dem Ausland sind willkommen. Schreiben Sie auf Deutsch, Englisch, Japanisch oder Französisch — wir antworten per E-Mail. Eine Installation in Korea wird nach Ortsbegehung kalkuliert. Inhalt kann als 4K-Video oder Live-Code remote geliefert werden.
