Wer wir sind

오늘은 봄날 ist ein frauengeführtes Media-Art-AX-Studio in Suseong-gu, Daegu, Republik Korea. Die öffentliche Seite ist publicbloom.art. Wir schneiden kein fertiges Video und gehen: Das Werk ist ein Programm, deshalb lässt sich dieselbe Arbeit erneut in 32:9 auf einer Außen-LED, in 9:16 auf einem Lobbysteelen oder gemappt auf eine Gebäudewand ausgeben. Wetter, Luftqualität oder die Datenbank der Institution können das Bild jeden Tag ändern. Fehlt noch ein Screen, installieren wir LED-Module oder eine Projektor-Medienfassade selbst.

Method

So entsteht die Arbeit

Eine Videodatei ist eine Lieferung. Code ist ein System, das dieselbe Datei in einem anderen Format neu drucken oder vor Ort weiterlaufen kann.

  1. 01

    Wir klären das Site-Spec: Verhältnis, Auflösung, Dauer, Helligkeit.

  2. 02

    Sie nutzen das Bomnal-Studio, oder wir liefern drei Entwürfe in einer Woche.

  3. 03

    Das freigegebene Stück wird auf dieses Panel gerendert. Werktagslieferung binnen 24 Stunden.

  4. 04

    Sie erhalten 4K-Video, Live-Code oder einen schlüsselfertigen Screen inkl. Montage.

Was ist 오늘은 봄날 (Oneul-eun Bomnal)?

오늘은 봄날 ist ein frauengeführtes Media-Art-Studio in Suseong-gu, Daegu, Korea. Die Website ist publicbloom.art. Das Studio schreibt Media Art in Code, produziert über eine KI-gestützte Pipeline und kann die LED oder Projektorfassade installieren. Inhaberin: Park Seongsil. Handelsregister 575-19-00976.

Was heißt „Media Art in Code“?

Das Bild erzeugt ein Programm, es wird nicht auf einer Timeline geschnitten. Dieselbe freigegebene Arbeit lässt sich in einem anderen Seitenverhältnis und einer anderen Auflösung neu ausgeben. Öffentliche Daten oder eine Institutsdatenbank können denselben Screen jeden Tag anders aussehen lassen. Wer nur eine Datei braucht, bekommt 4K auf Panelmaß.

Kann ein ausländisches Haus beauftragen?

Ja. Inhalt lässt sich remote spezifizieren, freigeben und als 4K oder Live-Code liefern. Schreiben Sie an studio@publicbloom.art auf Deutsch, Englisch, Japanisch oder Französisch. LED- oder Projektorinstallation in Korea nach Ortsbegehung. Außerhalb der genannten Regionen Einzelfall.

Warum zählt der Status als Frauenunternehmen in Korea?

오늘은 봄날 hält das Zertifikat Frauenunternehmen (Nr. 0113-2025-35456) und ist damit für die vorrangige öffentliche Beschaffung in Korea berechtigt. Dazu kommt das Direktproduktionszertifikat Videoproduktion (Nr. 2025-0495-02141) für beschränkte KMU-Ausschreibungen.

Wie schnell kommt der erste Entwurf?

Drei Entwürfe innerhalb einer Woche nach Briefing. Externes Video dauert oft einen Monat oder länger. Nach Freigabe geht der Werktagsrender binnen 24 Stunden raus (Wochenenden und koreanische Feiertage ausgenommen).

Medienfassade oder LED?

Medienfassade heißt hier Projektoren, gemappt auf eine vorhandene Wand, meist nachts. Ein LED-Display ist ein physischer Screen am Gebäude und kann tagsüber laufen. 오늘은 봄날 baut beides und empfiehlt nach Messung von Wand, Umlicht, Wurfweite und Strom.

Aufträge aus dem Ausland sind willkommen. Schreiben Sie auf Deutsch, Englisch, Japanisch oder Französisch — wir antworten per E-Mail. Eine Installation in Korea wird nach Ortsbegehung kalkuliert. Inhalt kann als 4K-Video oder Live-Code remote geliefert werden.
