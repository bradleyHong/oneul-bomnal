Qui nous sommes

오늘은 봄날 est un studio d’art médiatique AX, entreprise féminine établie à Suseong-gu, Daegu, République de Corée. Le site public est publicbloom.art. Nous n’éditons pas une vidéo pour disparaître : l’œuvre est un programme, donc la même pièce peut être rééditée en 32:9 sur une LED extérieure, en 9:16 sur un totem de hall, ou mappée sur un mur. Météo, qualité de l’air ou base de l’institution peuvent faire varier l’image chaque jour. S’il n’y a pas encore d’écran, nous installons nous-mêmes les panneaux LED ou la façade à projecteurs.

Method

Comment nous produisons

Un fichier vidéo est une livraison unique. Le code est un système qui peut réimprimer ce fichier dans un autre format, ou continuer de tourner sur place.

  1. 01

    Nous notons le cahier des charges : ratio, résolution, durée, luminosité.

  2. 02

    Vous essayez le studio Bomnal, ou nous renvoyons trois pistes en une semaine.

  3. 03

    La pièce validée est rendue pour ce panneau. Livraison en jour ouvrable sous 24 h.

  4. 04

    Vous recevez une vidéo 4K, du code temps réel, ou un écran clé en main avec pose.

FAQ

Questions fréquentes

Réponses autonomes, citables. Le détail des marchés publics coréens est sur le site en coréen.

Qu’est-ce qu’une façade média ?

C’est traiter une face de bâtiment comme un écran — LED dans l’architecture ou projection mappée sur le mur. Public Bloom (오늘은 봄날) produit l’art et peut poser le matériel dans le même contrat. Le site public est publicbloom.art.

Puis-je acheter de l’art pour une LED déjà posée ?

Oui. Ouvrez Media Art AX (studio Bomnal) sans compte, prévisualisez, puis nous rendons au ratio et à la résolution du panneau. Un boîtier HDMI suffit souvent. Le fichier part un jour ouvrable sous 24 h après accord.

Travaillez-vous seulement en Corée ?

Le studio est à Daegu. Les poses se concentrent sur Daegu, Busan et le Gyeongbuk ; Gyeongnam et Ulsan sur accord. À l’international, nous parlons d’abord d’une livraison de contenu à distance. Une pose hors de ces régions se discute au cas par cas — nous ne prétendons pas installer partout dans le monde.

Façade média ou mapping vidéo ?

La LED dans le bâtiment est un écran physique, utilisable de jour. Le mapping est de la lumière ajustée à une surface existante, surtout la nuit. Les deux sont dans le périmètre si le site le permet. Nous tranchons après le mur, la lumière, la distance de projection et l’électricité.

Les commandes depuis l’étranger sont les bienvenues. Écrivez en français, anglais, japonais ou allemand — nous répondons par courriel. Une installation en Corée se chiffre après visite de site. Le contenu peut être livré à distance en vidéo 4K ou en code temps réel.
