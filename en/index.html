Why Code

A video file only fits one wall

  1. Screens are never the same twiceRatio, resolution and loop length differ at every site. A work written in code is re-exported at 32:9, 16:9 or 9:16 from the same source, and pushed up to 4K or 5K. A delivered video file has to be remade each time the screen changes.
  2. The approved concept is the delivered workOur works are deterministic: the same seed on the same canvas always produces the same frames. What you sign off on is what arrives.
  3. The screen can change every dayWire a public API or an institutional database into the work and the wall reads differently each morning without anyone editing anything.
  4. One week, not one monthCommissioned video work usually runs a month or more. Ours takes a week to three concepts, because planning, copy, visuals and playback code are generated together from your house colours, typefaces and restrictions.
