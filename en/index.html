Who we are

오늘은 봄날 is a women-owned media-art AX studio based in Suseong-gu, Daegu, Republic of Korea. The public site is publicbloom.art. We do not edit a finished video and walk away: we write the artwork in code so the same piece can be re-rendered to a 32:9 outdoor LED, a 9:16 lobby totem, or a mapped building wall. When a live feed is useful, weather, air quality, or an institution’s own database can change the picture every day. When the site has no screen yet, we install LED panels or a projector media facade ourselves.

FAQ

Questions people ask first

Short answers you can quote. The Korean site has more detail for public procurement.

What is a media facade?

A media facade treats a building face as a display — either LED built into the architecture or projection mapped onto the wall. Public Bloom (오늘은 봄날) produces the media art and can install the hardware in one contract, so you do not brief a content studio and an electrician separately. The public site is publicbloom.art.

Can I buy media art for an LED I already have?

Yes. Open Media Art AX (Bomnal Studio) without an account, preview a screen, then we render to your aspect ratio and resolution. If the panel is already on the wall, an HDMI media box is often enough. Weekday file delivery is within 24 hours after you confirm.

Do you only work in Korea?

The studio is in Daegu. Installed sites are mainly Daegu, Busan, and Gyeongbuk, with Gyeongnam and Ulsan by arrangement. International buyers: we discuss remote content delivery first. Installation outside those Korean regions is case by case — we do not claim a worldwide install service.

Media facade versus projection mapping?

LED in the architecture is a physical screen that can run in daylight. Projection mapping is light fitted to an existing surface, usually at night. Both are in scope when the site fits. We recommend after looking at the wall, ambient light, throw distance, and power.

Overseas clients are welcome. Write in English, Japanese, French, or German — we reply by email. Installation in Korea is scheduled after a site survey; content can be delivered remotely as 4K video or live code.
