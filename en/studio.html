How overseas buyers purchase

  1. 1. Look

    Open Bomnal Studio (the editor is in Korean; the pictures are the brief). Or send a reference still and we return three concepts within a week.

FAQ

Buying questions

Commissioning from outside Korea.

Do I pay inside the studio?

Not yet. The studio is for choosing a look. Purchase and invoicing happen by email quote. Individuals and institutions both write to studio@publicbloom.art.

What files do I receive?

Usually a 4K mp4 cropped to your panel. If the screen should change with weather or data, you receive live code that runs on a player the studio can configure. If there is no screen, installation of LED or projectors can be added to the same conversation.

The studio UI is in Korean. Can I still use it?

Yes. You are choosing pictures, palettes, and motion — not writing Korean copy. If you prefer not to use the editor, send a reference image and request three concepts. This English page exists so the offer is clear before you open the tool.

Overseas clients are welcome. Write in English, Japanese, French, or German — we reply by email. Installation in Korea is scheduled after a site survey; content can be delivered remotely as 4K video or live code.
