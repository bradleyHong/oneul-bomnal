# 봄날 미디어박스 · USB 플레이어

고객이 **USB만 꽂으면** 화면이 도는 물건이다. 그 이상을 요구하면 결국 우리가 현장에 간다.

## 무엇을 하는가

- 꽂힌 USB를 스스로 찾는다. 경로를 물어보지 않는다.
- 안에 있는 영상을 **이름순**으로 재생한다. `01_`, `02_` 를 앞에 붙이면 그 순서다.
- 영상이 **한 편이면 그대로 반복**한다. 이어붙이지 않으므로 앞과 뒤가 끊기지 않는다.
- USB를 갈아 끼우면 몇 초 안에 알아서 갈아탄다. **다시 시작할 필요가 없다.**
- USB를 뽑아도 마지막 재생분을 복사해 두었다가 계속 돈다. **검은 화면이 뜨지 않는다.**
- 한 편이 안 열리면 다음 편으로 넘어간다. 전부 안 되면 쉬었다 다시 본다.
- 화면이 멈춘 것을 스스로 알아채고 되살린다.
- 하루에 한 번 스스로 새로 읽어 메모리를 비운다.

지원하는 파일 : `mp4` `m4v` `mov` `webm` `mkv` · `jpg` `png` `webp`

## 설치

라즈베리파이 OS(Desktop) 기준. 파이썬 말고는 아무것도 안 깐다.

```bash
sudo bash install.sh
```

운영 시간을 정하려면 이렇게 한다. 아래는 아침 8시부터 저녁 8시까지만 켜는 경우다.

```bash
sudo HOURS=08-20 bash install.sh
```

설치가 끝나면 전원을 넣는 것만으로 재생이 시작된다.

## 현장에서 화면 맞추기

설치할 때만 키보드를 붙인다. 평소에는 필요 없다.

| 키 | 하는 일 |
|---|---|
| `S` | 화면 맞추기 (채우기 · 회전 · 좌우반전 · 상하반전 · 사진 넘김 시간) |
| `D` | 상태 보기 (USB, 지금 트는 편, 연속 재생 시간, 마지막 오류) |
| `F` | 전체화면 켜고 끄기 |
| `←` `→` | 이전 · 다음 편 |
| `스페이스` | 멈춤 · 다시 재생 |

한글 자판이어도 된다. `ㄴ` `ㅇ` `ㄹ` 이 각각 `S` `D` `F` 자리다.

**화면 맞추기 값은 상자에 저장된다.** 전원을 껐다 켜도 그대로다. 세로로 세운 사이니지는 `회전 90°`, 거울에 반사시키는 설치는 `좌우 반전`을 쓴다.

## 손볼 일이 생기면

```bash
systemctl status bomnal-usb      # 지금 상태
journalctl -u bomnal-usb -f      # 무슨 일이 있었는지
systemctl restart bomnal-usb     # 다시 시작
```

## 시험용으로 돌려 보기

파이가 없어도 노트북에서 그대로 돈다.

```bash
python3 server.py --port 8181 --dir /경로/영상폴더
```

브라우저로 `http://127.0.0.1:8181/` 를 연다.

## 주소 뒤에 붙일 수 있는 것

| 값 | 예 | 뜻 |
|---|---|---|
| `hours` | `?hours=08-20` | 그 시간에만 켠다 (`22-06` 처럼 자정을 넘겨도 된다) |
| `fit` | `?fit=cover` | `contain` 여백 두기 · `cover` 꽉 채우기 · `fill` 늘이기 |
| `rotate` | `?rotate=90` | `0` `90` `180` `270` |
| `fliph` `flipv` | `?fliph=1` | 좌우 · 상하 반전 |
| `dwell` | `?dwell=30` | 사진 한 장을 몇 초 보여줄지 |

주소로 준 값이 저장된 값보다 우선한다. 현장에서 한 대만 다르게 맞출 때 쓴다.

## 알아 둘 것

- 서버는 `127.0.0.1` 에만 연다. 바깥에서 들어오지 못한다.
- 복사본은 `cache/` 에 쌓이고, 디스크 여유 2GB는 남긴다.
- 소리는 나오지 않는다. 브라우저가 자동재생을 막지 않게 하려면 음소거여야 한다.
  소리가 필요한 현장은 별도로 잡는다.
