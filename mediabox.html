장비만 보내드리지 않습니다. 기관 화면 규격에 맞춘 콘텐츠, 공공 API 연동, 관제 서버 등록까지 마친 상태로 납품하고, 설치 이후에는 원격으로 관리합니다.

  • 공공 API 실시간 연동 (공기질·기상·하천)
  • 24/7 자동 복구 · 원격 배포 · 운영 리포트

왜 맥미니인가

관공서 화면은 한번 설치하면 몇 년을 켜둔 채로 둡니다. 담당자가 매번 들여다볼 수 없기 때문에, 무엇보다 혼자서도 문제없이 계속 돌아가는 것이 중요합니다.

보안 디스크가 기본으로 암호화되어 있고, 서명되지 않은 프로그램은 실행되지 않습니다. 기관 내부망에 두어도 관리 부담이 적습니다.
안정성 발열과 전력 소모가 적어 팬 없이도 장시간 켜둘 수 있습니다. 화면이 멈추거나 다시 시작되는 일이 드뭅니다.
유지보수 운영체제 업데이트가 오래 지원되고, 고장 시 전국 어디서나 정품 서비스를 받을 수 있습니다.

소형 패널이나 행사용 임시 설치처럼 규모가 작은 현장에는 라즈베리파이 5를 씁니다. 현장 조건에 맞춰 실측 후 사양을 제안드립니다.

Turnkey Service

실측부터 원격 AS까지 한 계약으로.

시공업체·콘텐츠 외주·유지보수를 따로 찾을 필요 없이, 담당자는 창구 하나만 관리하면 됩니다.

  1. STEP 01

    로비 실측

    벽면·시야거리·조도·전기 용량을 실측해 최적 패널 사양을 산정합니다.

  2. STEP 02

    LED 설치

    패널 공급부터 구조 보강·배선·전원 계통까지 시공합니다.

  3. STEP 03

    하드웨어 설치

    미디어박스를 설치하고 관제 서버 연동까지 마쳐 인계합니다.

  4. STEP 04

    맞춤 콘텐츠

    기관 디자인 가이드와 보유 DB를 반영한 전용 아트를 제작합니다.

  5. STEP 05

    원격 AS

    이상을 자동 감지·복구하고 월간 리포트를 발행합니다.

현장 방문 실측은 대구·경북 무료 경남·부산·울산은 협의 후 방문, 그 외 지역은 도면·사진 기반 사전 검토 후 방문 일정을 조정합니다.
